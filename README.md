# 🔐 Random Password Generator

A simple Python program that generates random passwords based on the user's preferences.

## ✨ Features

- Choose a password length between **8 and 128 characters**
- Include or exclude:
  - Uppercase letters
  - Lowercase letters
  - Digits
  - Special characters
- Ensures at least one character from each selected character type
- Randomly shuffles the generated password

## 🛠️ Built With

- Python 3
- `random` module
- `string` module

- Add a graphical user interface (GUI)
